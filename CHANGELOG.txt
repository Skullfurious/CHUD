CHUD 1.0.1

RareScanner loading warning. CHUD no longer lists a file from RareScanner in its own load list, which made the game print "Error loading RareScanner/Tables/NpcInfoTables.lua" for anyone without RareScanner. Rare NPC spawn points and patrol paths are now built into CHUD in a single data file (RareData.lua), merged from the RareScanner and Questie databases with permission. No other addon is needed for rare markers. CHUD records your rare kills itself and hides those rares for 30 minutes. RareScanner is not needed; its kill records are honored too when it is installed.

Taint. CHUD no longer asks the game to rebuild its status bars when the default XP bar is shown again. Calling that from an addon taints the game's code and can block protected actions such as entering Edit Mode.

XP edge wave. The bright line at the end of the XP fill now ripples like the surface of a liquid. It has an XP Edge Wave checkbox in the Experience Bar settings, and /chud xpwave still toggles it. The wave is saved with themes, and every built-in theme has it on.

Icon Update Rate. The default is now 24 updates per second (was 12), for smoother icons while you move. Saved settings keep whatever value they have.

Simpler right-click menu. The menu now groups its options under Quests & Party, Rares & Treasures, Gathering, Highlight Node and Screen Marker (beta), with Data Sources and Refresh Gathering Data at the bottom. Everything else (Questie, display, icon style, party, fading, Delete Imported Gathering Data) sits behind an Advanced button, and the choice is remembered. Saved themes are listed above the built-in ones.

Theme import and export. Export shows a copyable code for the selected theme or your current look. Import adds a theme from a code into your Saved list. Codes are read by CHUD's own parser, only known theme settings are accepted, and fonts are not imported.

Known Spawns. The extra checkbox in Data Sources is renamed and explained: it adds the built-in rare spawn points and patrol paths to the game's own live rare markers.

Rare patrol paths. A rare with a long patrol path (14 points for the Sewer Beast) drew one icon per point. It is now one marker at the point nearest you.

Herbs and ore inside cities. Some source data places herb and ore points inside capital cities, which showed phantom icons on the bar. A refresh now skips them. Chests are unaffected.

Refresh Gathering Data and GatherLite tracking. GatherLite only loads herbs, ore or chests while that type is tracked for your character, so a refresh could come back empty. CHUD now switches an untracked type on just long enough to read it and puts it back as it was. A refresh also only adds nodes now. It carries over everything CHUD already holds, so a source that returns nothing at that moment no longer wipes your herbs and ore. Delete Imported Data is the way to clear them.

Highlight Node and NPC nameplates. Highlight Node stays on by default. It uses the game's soft interact targeting, which also puts a nameplate on nearby NPCs you can interact with. CHUD now says so on the setup tour's data page, when you turn the option on, and in its tooltip. Turn it off to stop the nameplates; your own game settings are put back.

CHUD 1.0

Gathering nodes. Herbs, ore and chests now come from GatherLite (recommended, it has all three) or GatherMate2 with GatherMate2_Data (herbs and ore), plus the spots you gather yourself. CHUD imports them into its own saved copy only when you ask (in the setup tour or with the Refresh Gathering Data button), so it keeps working if you remove them later. Delete Imported Data erases the copy. The nearest 8 of each kind show on the bar, bigger as you get closer. If both addons are on, the menu suggests turning GatherMate2 off because they overlap.

Next Node pointer. One large pointer for the nearest herb, ore or chest you have not visited, with a button to limit it to one kind. Being within 12 yards for half a second counts as a visit, even if you leave the radius again. Visited and skipped nodes return after 10 minutes (chests 20). Right-click any node to skip it.

Off-bar pointer. When the Next Node is outside the bar it stays pinned to the edge at no less than 65% opacity instead of fading out. Only Show Next Node hides every other herb, ore and chest icon and is on by default; the setup tour has the checkbox and its demo markers show the difference. Delete Imported Data in the marker menu erases CHUD's own copy of the gathering data.

Highlight Node. Close to the pointer, CHUD draws brackets and a ring on the real herb, vein or chest using the game's own interact targeting. If you are facing the spot and nothing is there, a short "Node Not Here" effect plays and the pointer moves on. It changes a few game targeting settings, only the ones that differ, and gives them back when you turn it off or log out.

Rare NPCs. About 420 rare NPCs with spawn points and patrol paths are built into CHUD. CHUD records your rare kills and hides those rares for 30 minutes.

Party and corpse. Party members get a role or class icon on the bar, glide smoothly between the game's position updates, and are hidden while offline. Your corpse is marked while you are a ghost.

Screen Marker (experimental, off by default). A beam, ring and pin where the game puts its waypoint pin for the Next Node. It follows the game's own pin, so it can sit off on slopes.

Fresh start. Everyone, including anyone upgrading, gets a fresh install the first time 1.0 loads: settings and imported data from earlier versions are cleared once and the setup tour opens. Saved themes and recorded gathering spots are kept.

Setup tour. The first time CHUD loads it opens a short tour (with twelve demo markers placed all the way around the bar while it is open, so there is always something to see; they never appear otherwise): pick a look from a row of theme swatches, choose what the bar points to, see which gathering and rare data addons were found and how the import works (with an Import button), and decide on fading. The bar behind the window updates live. /chud install runs it again.

New themes. Rose Pine, Gruvbox, Dracula, Kanagawa and Everforest, plus an original retro neon one called Synthwave. Horde's XP fill is brighter so it can be seen against its plate.

XP per hour. When you have no rested XP, the XP tooltip's Rested line becomes XP/h, your monster-kill experience rate over the last 10 minutes (quests and exploration are not counted; shown as -- until you have a kill and have played a minute).

Default XP bar. The game's own experience bar is now hidden by default since CHUD has its own XP fill. The last page of the setup tour says so and has a checkbox to bring it back (also the Default XP Bar button in /chud).

Fading. Optional, off by default. Fade Out When Idle makes the bar fade away unless something you tick in Show When is happening: combat, the map or quest log open, the mouse over the bar or minimap, running, autorun (also follow and flight paths), or being dead. Faded Opacity and Master Opacity sliders are in More Options.

Menu. The marker menu has a Quick Toggles grid, a Data Sources section that shows which addons were found, and the remaining options in a panel beside it. Every control now has a tooltip that describes what it really does.

Commands. /chud, /chud unlock, /chud lock, /chud center, /chud reset and /chud install (after a confirmation it resets every setting and the imported data, then runs the tour as on a first install). /chud debug gathers the diagnostic reports into one copyable window.

Fixes and cleanup. A full reset now keeps your imported gathering data and the saved game settings Highlight Node has to give back. Unused code, settings and old comments were removed.

CHUD 0.5.0

Questie support. If Questie is installed, CHUD picks up its quest objectives, turn-ins and quest givers and shows them on the bar with Questie's own icons. It switches on by itself and only reads from Questie, it never changes anything there. If one of Questie's own settings is hiding something, the matching CHUD option greys out and its tooltip tells you what to turn on.

Focused quest. Your focused quest gets a bigger icon (it never makes the bar taller) and its other objectives still show as normal icons. Click any smaller objective on the bar to focus that quest. There's a Focused Quest Only option, and the focused icon can glow while you're standing in the quest area.

Less clutter. Only the nearest icon of each objective type per quest is shown. Objectives and quest givers shrink and fade the farther away they are, with their own Fade Distance sliders (default 300 yd). Questie Max Distance defaults to 600 yd and goes up to 1000.

Smoother icons. Nearby icons used to jump four times a second. They now update up to 12 times a second while you move, and there's an Icon Update Rate slider if you want to trade smoothness for CPU.

New options. Icons Outside Bar puts the icons just past the edge of the bar. A button at the bottom of the settings page shows or hides the default XP bar.

Themes. Two new themes, Catppuccin and Tokyo Night. A new Daylight checkbox next to the theme list changes the colors with the in-game clock every half hour and locks the color controls while it's on.

Performance. The marker code uses roughly a third of the CPU it did before.

Settings menu. Everything in Display and Experience Bar, plus all the buttons, now has a tooltip.

Your 0.3.0 settings carry over, so the new default distances only apply if you reset them.
